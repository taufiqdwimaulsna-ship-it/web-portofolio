Website portofolio responsif yang dibuat menggunakan **HTML5**, **CSS3**, dan **JavaScript** murni (Vanilla JS), serta dipublikasikan secara publik menggunakan **GitHub Pages**. Project ini dibuat untuk memenuhi tugas mata pelajaran **Pemrograman Web**.

---

## ✨ Fitur Utama

- **6 Bagian Lengkap:** Home, About, Skills, Projects, Pendidikan, dan Contact.
- **Mode Malam & Mode Terang (Dark / Light Mode):** Dilengkapi tombol pengubah tema dengan penyimpanan otomatis di browser (`localStorage`).
- **Efek Mengetik Otomatis (Typing Effect):** Animasi teks interaktif pada halaman utama menggunakan JavaScript.
- **Galeri Project & Tautan:** Menampilkan gambar preview proyek beserta tombol tautan langsung menuju repository GitHub.
- **Desain Responsif:** Tampilan menyesuaikan layar desktop, tablet, maupun smartphone dengan menu navigasi mobile.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Struktur semantik halaman website
- **CSS3** — Styling modern dengan CSS Variables, Flexbox, CSS Grid, dan transisi tema
- **JavaScript (ES6+)** — Interaktivitas DOM, *typing animation*, toggle menu mobile, dan *theme switcher*
- **GitHub Pages** — Hosting publik gratis untuk mempublikasikan website
